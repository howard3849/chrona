Use this process each version.

cd "/Users/Admin/Library/Mobile Documents/com~apple~CloudDocs/Projects/Chrona"

unzip -o "/path/to/downloaded/Chrona-version.zip" -d "/tmp/chrona-update"

rsync -av \
  --exclude='.git' \
  "/tmp/chrona-update/Chrona/" \
  "/Users/Admin/Library/Mobile Documents/com~apple~CloudDocs/Projects/Chrona/"

The important part is:

--exclude='.git'

That copies updated project files without touching your repository metadata.
