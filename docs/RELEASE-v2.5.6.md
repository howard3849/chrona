# Chrona v2.5.6

Introduces the shared Neutral Studio application shell for all visual themes.

- Adds coordinated light and dark surface tokens.
- Gives the timeline canvas a restrained porcelain/charcoal depth treatment.
- Gives the radar a distinct layered navigator surface and glass-like focus window.
- Keeps AI, Gradient, Flat, and Metro identities confined to event surfaces and connectors.
- Refines neutral borders, axis colors, typography, and control surfaces without changing timeline behavior.
