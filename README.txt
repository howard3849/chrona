Chrona v1.36

Changes from v1.34:
- Duration span bars are now 3 px thick instead of 2 px.
- The first span remains separated from the 1 px timeline axis by a 1 px visual gap.
- Overlapping span micro-lanes now use a 4 px pitch: 3 px span plus 1 px separation.
- Start-date anchors, connectors, end caps, period labels, and all v1.34 rendering fixes remain unchanged.


v1.36: Reset now clears stale pointer/drag state and window-level pointer-end fallbacks keep hover tooltips active after reset.
